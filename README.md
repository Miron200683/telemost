# telemost — Яндекс Телемост для Linux

Приложение навайбкодил Claude, не исключены баги. Но я им пользуюсь вполне нормально. Сам работаю в поддержке одного из сервиса Яндекс. В редких случаях иногда приходится перезапускать приложение.

Неофициальный десктопный клиент [Яндекс Телемоста](https://telemost.yandex.ru) в формате **AppImage**, сделанный с прицелом на **KDE Plasma**: нативные уведомления со звуком и аватарками, значок в трее с индикатором непрочитанных, автозагрузка и открытие ссылок во внешнем браузере.

✅ Работоспособность проверена в **Arch Linux** с окружением **KDE Plasma (Wayland)**.

> Это независимый проект, он не связан с Яндексом и не одобрен им. Название «Яндекс Телемост» и иконка принадлежат их владельцам. Приложение — это обёртка над официальным сайтом: никакие данные никуда, кроме серверов Яндекса, не отправляются.

## Возможности

**Уведомления**
- Нативные уведомления Plasma через DBus (`libnotify`), с именем и иконкой приложения.
- Аватарка собеседника в уведомлении, если сайт передаёт её вместе с сообщением. Если нет — показывается иконка приложения.
- Звуковой сигнал при новом уведомлении. Звук не играет при включённом режиме «Не беспокоить» в KDE, а серия сообщений подряд даёт один сигнал.
- Клик по уведомлению разворачивает окно.

**Индикатор непрочитанных**
- Красный бейдж с числом на иконке в трее и в окне (после 9 показывается «9+»).
- Бейдж на значке в панели задач Plasma (протокол `com.canonical.Unity.LauncherEntry`).
- Сбрасывается, когда вы открываете окно.

**Трей и запуск**
- Закрытие окна сворачивает приложение в трей, уведомления продолжают приходить.
- Пункты меню трея: открыть, звук уведомлений, проверить звук, тестовое уведомление, запуск при входе в систему, перезапуск, выход.
- Автозагрузка (XDG autostart) с запуском сразу в трей (`--hidden`).
- Только один экземпляр: повторный запуск просто показывает окно.

**Звонки и браузер**
- Камера и микрофон, доступ разрешён только доменам Яндекса.
- Демонстрация экрана: на Wayland через PipeWire/xdg-desktop-portal, на X11 приложение само спрашивает, какой экран или окно показать.
- Ссылки из чатов открываются во внешнем браузере (клик, ctrl+клик, средняя кнопка). Внутри остаются только окна входа Яндекса.
- Контекстное меню: «Открыть ссылку в браузере», «Копировать адрес ссылки», вставка и копирование в поле ввода.

## Требования

- Linux x86_64 с графической сессией (Wayland или X11). Лучше всего работает в KDE Plasma.
- Сервис уведомлений на DBus (в Plasma есть из коробки) и `libnotify`.
- **FUSE 2** для запуска AppImage: пакет `fuse2` (Arch), `libfuse2` / `libfuse2t64` (Ubuntu, Debian), `fuse-libs` (Fedora).
- Для демонстрации экрана на Wayland: `pipewire` и `xdg-desktop-portal` (в KDE — `xdg-desktop-portal-kde`).

## Установка

1. Скачайте `Yandex-Telemost-1.3.7-x86_64.AppImage` из раздела [Releases](https://github.com/Miron200683/telemost/releases).
2. Сделайте файл исполняемым и запустите:
   ```bash
   chmod +x Yandex-Telemost-1.3.7-x86_64.AppImage
   ./Yandex-Telemost-1.3.7-x86_64.AppImage
   ```
3. Чтобы в меню приложений появился ярлык, добавьте файл через [Gear Lever](https://github.com/mijorus/gearlever) или [AppImageLauncher](https://github.com/TheAssassin/AppImageLauncher). Положите AppImage в постоянное место (например, `~/Applications`) до добавления.

### Arch Linux: установка пакетом (без AppImage)

В папке `arch/` лежит `PKGBUILD`. Пакет использует системный `electron`, весит около 300 КБ, а ярлык и иконка ставятся в систему сами:

```bash
git clone https://github.com/Miron200683/telemost.git
cd telemost/arch
makepkg -si
```

Либо скачайте готовый `yandex-telemost-1.3.7-1-any.pkg.tar.zst` из Releases и поставьте: `sudo pacman -U yandex-telemost-1.3.7-1-any.pkg.tar.zst`. Запуск: `yandex-telemost` или из меню приложений. Если системный `electron` слишком новый и что-то ведёт себя странно: `ELECTRON_BIN=electron33 yandex-telemost`.

### Запуск AppImage без FUSE

Если FUSE не настроен, можно запускать без монтирования:
```bash
./Yandex-Telemost-1.3.7-x86_64.AppImage --appimage-extract-and-run
```

## Параметры запуска и переменные окружения

| Параметр | Что делает |
|---|---|
| `--hidden` / `--minimized` | Запуск сразу в трей, без показа окна |
| `--no-sandbox`, `--disable-dev-shm-usage` | Флаги Chromium на случай проблем с запуском (см. ниже) |
| `TELEMOST_DEBUG=1` | Печатает в консоль параметры уведомлений, загрузку аватарок и ошибки бейджа |
| `TELEMOST_DESKTOP_ID=имя.desktop` | Имя ярлыка, к которому привязывается бейдж в панели задач (по умолчанию `yandex-telemost.desktop`) |

## Автозагрузка

Правый клик по иконке в трее, затем отметьте «Запускать при входе в систему». Приложение создаст `~/.config/autostart/yandex-telemost.desktop` с командой запуска `--hidden`. Чтобы отключить, снимите ту же галочку.

Если вы переместили или переименовали AppImage (например, при обновлении версии), переключите галочку выкл/вкл, чтобы путь обновился.

## Сборка из исходников

Нужны Node.js 20+ и npm.

```bash
git clone https://github.com/Miron200683/telemost.git
cd telemost
npm install
npm start          # запуск для проверки
npm run dist       # сборка AppImage в папку dist/
```

Сборка в GitHub Actions: workflow `.github/workflows/build.yml` запускается при пуше тега `v*` (или вручную во вкладке [Actions](https://github.com/Miron200683/telemost/actions)) и сохраняет готовый AppImage как артефакт сборки. Чтобы выпустить релиз, создайте тег (`git tag v1.3.7 && git push --tags`), скачайте артефакт и приложите AppImage к релизу в разделе Releases.

### Структура проекта

```
main.js          # главный процесс: окно, трей, уведомления, звук, бейдж, автозагрузка
preload.js       # подмена Notification на странице, мост к главному процессу
restart.js       # безопасный перезапуск AppImage (очистка окружения)
build/icon.png   # иконка приложения
build/sound/     # звук уведомления и вспомогательная страница (звук, рисование бейджа)
arch/            # PKGBUILD и файлы для пакета Arch Linux
```

## Как устроены уведомления

Сайт показывает уведомления через браузерный `Notification`. Скрипт `preload.js` подменяет его на странице: данные уходят в главный процесс, он скачивает аватарку (с вашими куки, только по `https`), показывает уведомление через Electron (то есть через DBus/libnotify), проигрывает звук и увеличивает счётчик. Уведомления с одинаковым `tag` заменяют друг друга.

## Решение проблем

**Приложение не запускается, ошибка про `/dev/shm`, `trap int3`.** Запустите с флагами:
```bash
./Yandex-Telemost-1.3.7-x86_64.AppImage --no-sandbox --disable-dev-shm-usage
```
По умолчанию они отключены, так как могут снижать производительность.

**Ошибка «Cannot mount AppImage, please check your FUSE setup».** Установите FUSE 2 (см. «Требования») или запускайте с `--appimage-extract-and-run`. Если такая ошибка появлялась только при «Перезапустить» в меню трея, обновитесь до версии 1.3.7 или новее: там перезапуск исправлен.

**Не приходят уведомления.**
1. В меню трея выберите «Тестовое уведомление». Если оно не появилось, проблема в системе: проверьте режим «Не беспокоить» (он может включаться сам при показе экрана) и настройки в *Параметры системы → Уведомления*.
2. Если тестовое пришло, а из чата нет, запустите с отладкой и дождитесь сообщения:
   ```bash
   TELEMOST_DEBUG=1 ./Yandex-Telemost-1.3.7-x86_64.AppImage 2>&1 | grep -E "notify|badge|avatar"
   ```
   Строка `[notify] received` значит, что сайт прислал уведомление, `shown` — что оно показано.

**Нет аватарки в уведомлении.** Она показывается только если сайт передаёт её вместе с уведомлением. Проверить можно через `TELEMOST_DEBUG=1`: в строке `[notify]` будет адрес картинки.

**Нет бейджа на значке в панели задач.** Он привязывается к имени ярлыка. Если ваш ярлык называется иначе (например, его создал Gear Lever), запустите с `TELEMOST_DESKTOP_ID=имя-вашего-ярлыка.desktop`. Имя файла можно найти в `~/.local/share/applications/`. Бейдж в трее работает независимо от этого.

**Предупреждения Fontconfig в консоли** (`invalid attribute 'xsi:nil'`) безвредны и на работу не влияют.

## Ограничения

- Счётчик непрочитанных приблизительный: он считает уведомления, пришедшие, пока окно не в фокусе, а не реальные непрочитанные сообщения Телемоста.
- Только x86_64. Автообновления нет: новые версии нужно скачивать вручную.
- Проверено в Arch Linux с KDE Plasma (Wayland). В других дистрибутивах и окружениях (GNOME, X11 и т.д.) трей, бейдж в панели задач и уведомления могут работать иначе.

## Сообщить об ошибке

Нашли проблему или хотите предложить улучшение? Создайте [issue](https://github.com/Miron200683/telemost/issues). Чтобы разобраться было проще, укажите дистрибутив, окружение (KDE/GNOME, Wayland/X11), версию приложения и приложите вывод запуска с отладкой:

```bash
TELEMOST_DEBUG=1 ./Yandex-Telemost-1.3.7-x86_64.AppImage 2>&1 | grep -v Fontconfig
```

## Данные и удаление

Если ставили пакетом для Arch: `sudo pacman -Rns yandex-telemost`. Если AppImage: удалите сам файл.

Настройки, куки и вход в аккаунт хранятся в `~/.config/Яндекс Телемост/`. Чтобы стереть всё без следа, удалите (по желанию) эту папку и файл `~/.config/autostart/yandex-telemost.desktop`.

```bash
rm -rf ~/.config/"Яндекс Телемост"
rm -f ~/.config/autostart/yandex-telemost.desktop
```
